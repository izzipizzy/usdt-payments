# Скриншоты инструкции

Это скриншоты собранной админки с демонстрационными ответами API. Все обращения к `/admin/v1/` перехватываются в отдельном браузерном контексте; внешние запросы блокируются. Скрипт не авторизуется в настоящем API, не создаёт кошельки, не меняет настройки и не отправляет транзакции.

Адреса, балансы, API key, номер выплаты и история вымышленные. Префиксы `TMAIN`, `TPOOL`, `TDEMO` обозначают разные роли адресов; это не адреса для переводов. Seed-фраза и QR-код аутентификатора не снимаются.

Для обновления нужны запущенная админка, Playwright и установленный Chromium для этой версии Playwright:

```bash
node docs/screenshots/capture.mjs
```

`SCREENSHOT_BASE_URL` меняет адрес админки (по умолчанию `http://127.0.0.1:8080`). Если Playwright установлен отдельно, `PLAYWRIGHT_MODULE` указывает на его `index.mjs`. `PLAYWRIGHT_CHROMIUM` позволяет указать путь к уже установленному Chromium.

Скрипт делает RU/EN-снимки одинаковых экранов и сохраняет описание в `manifest.json`. Неизвестный запрос к API или ошибка приложения завершают генерацию с ошибкой. После обновления проверьте изображения визуально и ссылки в README.
